Formula Prioritas
PRIORITAS = (sks × 10) + (wajib ? 20 : 0) + (7 - semester) // MK01: (3×10) + 20 + (7-2) = 85 // MK03: (3×10) + 20 + (7-5) = 72 // MK02: (2×10) + 20 + (7-2) = 65
